## Distinguish a gap from missing information
A vague symptom calls for clarification before a failed-document conclusion. Distinguish an unsupported model, unknown revision, missing public manual, restricted service procedure, superseded source and a retrieval miss despite available content.
## Recovery and escalation
Consult authorized customer manuals, retain candidate scores and specific denials, then ask a useful follow-up if information can resolve the uncertainty. Continue valid ordered steps without counting each step as a failed reasoning attempt. Escalate after a genuine unsupported condition, exhausted authorized sequence, repeated unproductive recovery or a mandatory safety condition.
## Contradictory control
If an approved-looking document contradicts a fixed safety, disclosure or human-approval boundary, record both references and block the affected instruction or transaction. Request a documentation review. Neither semantic similarity nor a local model decision can override the boundary.
